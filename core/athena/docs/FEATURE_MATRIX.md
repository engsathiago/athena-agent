# Matriz de recursos da Athena

| Área | Implementação | Estado |
|---|---|---|
| Ciclo do agente | Streaming multiprovedor e uso de ferramentas | Entregue |
| Terminal | CLI conversacional rica e TUI opcional | Entregue |
| Modelos | Nuvem, Ollama Cloud e endpoints compatíveis | Entregue |
| Ferramentas | Terminal, arquivos, navegador, web, MCP e plugins | Entregue |
| Sessões | Conversas persistentes, retomada e compressão | Entregue |
| Mensagens | Telegram e adaptadores do gateway | Entregue |
| Agentes | Perfis, identidades e workspaces isolados | Entregue |
| Roteamento | Bindings por plataforma, usuário, chat e tópico | Entregue |
| Autonomia | Cron e heartbeat em horários ativos | Entregue |
| Memória | SQLite FTS5, procedência e auditoria | Entregue |
| Segurança | Modos `unrestricted`, `controlled` e `core` | Entregue |
| Serviço | Inicialização contínua do gateway | Entregue |
| Instalador | Runtime privado, comando global e estado isolado | Entregue |
| Controle remoto | Dispositivos auxiliares com escopo | Futuro |
